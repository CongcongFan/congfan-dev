# Memory Distillation Workspace

This folder is for turning private memory exports into public-safe site knowledge.

- `chatgpt/`: private ChatGPT memory exports or notes.
- `codex/`: private Codex memory exports or notes.
- `distilled/`: reviewed, public-safe outputs that may be used by the site assistant.

Do not commit raw memory exports, secrets, private customer details, local paths, API tokens, or account configuration. Only reviewed distilled outputs should be considered for public use.
